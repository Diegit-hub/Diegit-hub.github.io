03 · Le plat principal

Mes projets

Projet de cours · Avril 2026

Centre de Formation, une application web de gestion des formations

Une application qui permet à un centre de formation de gérer son catalogue : créer des formations, y affecter des formateurs et suivre les inscriptions des stagiaires. Chaque utilisateur se connecte et ne voit que ce que son rôle lui permet.

Les ingrédients

Java (POO) Maven Apache Tomcat MySQL SQL VS Code

Trois rôles, trois espaces

AdministrateurGère les formations et les formateurs
FormateurConsulte ses formations et ses stagiaires
StagiaireCrée son compte, s'inscrit et se désinscrit

La recette

  1. Authentification avec trois rôles et des droits différents selon le profil
  2. CRUD complet sur les formations : création, affichage, modification, suppression
  3. Inscription libre des stagiaires ; les formateurs sont créés uniquement par l'administrateur
  4. Réaffectation d'un formateur à une formation depuis un menu déroulant
  5. Règle métier : une formation ne peut être supprimée que si plus aucun stagiaire n'y est inscrit
  6. Guide de démarrage et d'utilisation rédigé pour installer et tester le projet
